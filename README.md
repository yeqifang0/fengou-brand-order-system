```bash
# 浏览器访问 http://127.0.0.1:8790
```

## 四、核心业务规则

- 价格引擎：成交价 = 单独定价 > 吊牌价 × 等级折扣（金牌 4.2 折 / 银牌 4.5 折 / 铜牌 4.8 折）。
- 订货流程：经销商提交 → 品牌方审核（通过即锁定 SKU 可订库存并占用授信）→ 锁款 → 排产标记 → 完成（扣减现货、释放锁定）。
- 授信校验：提交订单时校验「授信额度 − 在途订单占用」，超额禁止提交。
- 补货通过 = 锁库存；退货通过 = 恢复可订库存并释放锁定。
- 数据隔离：经销商端全部查询按登录身份过滤；页面底部统一标注「技术支持：诩可科技（上海诩可科技有限公司）」。
